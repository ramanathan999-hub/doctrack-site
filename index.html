02 — Signature workflows

Build the workflow once. Run it on every order.

Every order type has its own document chain. International shipments need customs docs. New suppliers need NDAs and T&Cs before anything moves. DocTrack lets you define each workflow once — then runs it automatically on every matching order.

  • Define workflows by order type — domestic, international, new supplier, returns
  • Sequential or parallel signing — internal approvals before external parties
  • Conditional routing — different docs required above certain order values
  • Automatic reminders to suppliers and customers who haven't signed
  • Full audit trail per order — every signature, every timestamp, exportable

End to end

From order raised to fully documented

01

Order is raised

A new order triggers DocTrack — from your system, manually, or via webhook. The right document workflow kicks off automatically.

04
